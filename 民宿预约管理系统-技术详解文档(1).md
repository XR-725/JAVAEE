## 1. 项目概述

民宿预约管理系统是一个完整的全栈 Web 应用，支持 **三角色权限体系**（系统管理员 admin、房东 host、普通用户 user），实现了从民宿发布、审核上架、用户浏览预订、支付确认、入住完成到评价反馈的**完整业务闭环**。

### 功能全景

| 角色 | 核心功能 |
|------|---------|
| **普通用户 (user)** | 浏览民宿列表/详情、搜索筛选、预订房间、支付、取消订单、评价打分、收藏民宿、个人信息管理 |
| **房东 (host)** | 发布/编辑/删除民宿、房型管理、订单确认/办理入住/完成、收益报表 |
| **管理员 (admin)** | 仪表盘总览、用户管理、民宿审核上下架、订单管理、评价管理、Banner/公告管理、系统配置、操作日志、数据统计 |

### 3.2 JWT + Spring Security 认证授权体系

#### 3.2.1 认证流程概述

```
用户登录请求
    ↓
UserController.login()  →  验证账号密码
    ↓
JwtUtils.generateToken()  →  生成 JWT（含 userId, username, role）
    ↓
返回 Token + 用户信息给前端
    ↓
前端将 Token 存入 localStorage
    ↓
后续请求 → Axios 拦截器自动添加 Authorization: Bearer <token>
    ↓
JwtAuthenticationFilter  →  解析验证 Token → 注入 SecurityContext
    ↓
@PreAuthorize 注解  →  检查角色权限
```

#### 3.2.2 JWT 工具类

**代码位置**: `homestay-booking/src/main/java/com/homestay/utils/JwtUtils.java`

```java
@Component
public class JwtUtils {
    @Value("${jwt.secret}")       // 从 application.yml 读取密钥
    private String secret;
    @Value("${jwt.expiration}")   // 读取过期时间
    private Long expiration;

    // 生成 Token：将 userId、username、role 写入 Payload
    public String generateToken(Long userId, String username, String role) {
        Date expireDate = new Date(System.currentTimeMillis() + expiration);
        return JWT.create()
            .withClaim("userId", userId)
            .withClaim("username", username)
            .withClaim("role", role)
            .withExpiresAt(expireDate)
            .sign(Algorithm.HMAC256(secret));  // HMAC256 签名
    }

    // 验证 Token 是否有效（检查签名 + 过期时间）
    public boolean validateToken(String token) {
        try { parseToken(token); return true; }
        catch (Exception e) { return false; }
    }
}
```

**关键技术点**:
- 使用 `auth0/java-jwt` 库进行 JWT 操作（非 jjwt）
- HMAC256 对称签名算法
- Token 有效期 7 天（604800000 毫秒）
- 无状态认证，不依赖 Session，服务端无需存储 Token

#### 3.2.3 JWT 认证过滤器

**代码位置**: `homestay-booking/src/main/java/com/homestay/config/JwtAuthenticationFilter.java`

```java
@Component
public class JwtAuthenticationFilter extends OncePerRequestFilter {
    @Override
    protected void doFilterInternal(HttpServletRequest request, ...) {
        // 1. 从请求头获取 Bearer Token
        String token = getTokenFromRequest(request);
        
        // 2. 验证 Token 有效性
        if (StringUtils.hasText(token) && jwtUtils.validateToken(token)) {
            // 3. 解析用户名，加载用户详情
            String username = jwtUtils.getUsernameFromToken(token);
            UserDetails userDetails = userDetailsService.loadUserByUsername(username);
            
            // 4. 创建认证对象，注入 SecurityContext
            UsernamePasswordAuthenticationToken authentication = 
                new UsernamePasswordAuthenticationToken(userDetails, null, userDetails.getAuthorities());
            SecurityContextHolder.getContext().setAuthentication(authentication);
        }
        filterChain.doFilter(request, response);
    }
}
```

**运行机制**:
- 继承 `OncePerRequestFilter`，每个请求只执行一次过滤
- 自动从 `Authorization: Bearer xxx` 头提取 Token
- 验证通过后注入 Spring Security 上下文，后续 Controller 可通过 `SecurityUtils.getCurrentUserId()` 获取用户ID

#### 3.2.4 安全配置与权限规则

**代码位置**: `homestay-booking/src/main/java/com/homestay/config/SecurityConfig.java`

```java
@EnableWebSecurity
@EnableGlobalMethodSecurity(prePostEnabled = true)  // 启用方法级权限注解
public class SecurityConfig {
    @Bean
    public SecurityFilterChain securityFilterChain(HttpSecurity http) {
        http
            .cors().and()                              // 允许跨域
            .csrf(csrf -> csrf.disable())              // 关闭 CSRF（前后端分离）
            .sessionManagement(s -> s.sessionCreationPolicy(STATELESS))  // 无状态
            .authorizeRequests(requests -> requests
                // ── 公开接口（无需登录）──
                .antMatchers(
                    "/api/user/login",          // 登录
                    "/api/user/register",       // 注册
                    "/api/homestay/list",       // 民宿列表
                    "/api/homestay/detail/**",  // 民宿详情
                    "/api/homestay/hot",        // 热门民宿
                    "/api/homestay/recommend",  // 推荐民宿
                    "/api/room/list/**",        // 房型列表
                    "/api/review/homestay/**",  // 民宿评价
                    "/api/review/stats/**",     // 评价统计
                    "/api/banner/list",         // 轮播图列表
                    "/api/notice/list",         // 公告列表
                    "/uploads/**",              // 静态资源
                    "/doc.html"                 // Swagger 文档
                ).permitAll()
                .anyRequest().authenticated()         // 其他接口需要登录
            )
            .addFilterBefore(jwtAuthenticationFilter, ...);  // 在密码认证前插入 JWT 过滤器
    }
}
```

**权限控制注解使用示例**（在 Controller 方法上）:

```java
// 只有 HOST 或 ADMIN 角色可以发布民宿

public Result<?> add(@Valid @RequestBody HomestayDto dto) { ... }

// 只有 ADMIN 角色可以审核民宿状态

```

**多角色支持机制**:
- 用户 `role` 字段为逗号分隔字符串，如 `"host,admin"`
- 自定义 UserDetailsService 将逗号分隔字符串解析为多个 `SimpleGrantedAuthority`
- admin 账户同时拥有 `ROLE_HOST` 和 `ROLE_ADMIN` 权限

**房间可用性算法** (`checkRoomAvailable`):

```java
public boolean checkRoomAvailable(Long roomId, LocalDate checkIn, LocalDate checkOut, int requestRoomCount) {
    int totalCount = room.getTotalCount();  // 该房型总间数

    // 查询冲突订单（与请求日期段重叠的未完成订单）
    List<Orders> conflictOrders = ordersMapper.selectList(
        new LambdaQueryWrapper<Orders>()
            .eq(Orders::getRoomId, roomId)
            .in(Orders::getStatus, "pending", "paid", "confirmed", "check_in")  // 未完成状态
            .lt(Orders::getCheckInDate, checkOut)    // 冲突订单入住 < 请求退房
            .gt(Orders::getCheckOutDate, checkIn)    // 冲突订单退房 > 请求入住
    );

    int bookedCount = conflictOrders.stream()
        .mapToInt(Orders::getRoomCount).sum();  // 已被预订的总间数

    return (totalCount - bookedCount) >= requestRoomCount;  // 剩余间数是否满足
}
```

#### 4.2.2 导航守卫 — 多角色权限路由

**代码位置**: `homestay-booking-web/src/router/index.js` → `router.beforeEach()`

守卫逻辑流程图：

```
请求访问页面
    ↓
┌─ 页面需要登录 (meta.requiresAuth) 且没有 Token？
│  → 跳转 /login，携带 redirect 参数
│
├─ 已登录，访问 /login 或 /register？
│  → 根据角色自动跳转（admin→/admin, host→/host, user→/home）
│
├─ 管理员禁止访问普通用户功能（收藏/评价/订单列表）？
│  → 跳转 /admin
│
├─ 页面需要特定角色 (meta.role)？
│  → 检查用户角色是否匹配，不匹配跳转 /home
│
└─ 放行
```

**核心代码**:

```js
router.beforeEach((to, from, next) => {
  const token = localStorage.getItem('token')
  const userInfo = JSON.parse(localStorage.getItem('userInfo') || '{}')

  // 1. 需要认证但未登录 → 跳转登录页
  if (to.meta.requiresAuth && !token) {
    next({ name: 'Login', query: { redirect: to.fullPath } })
    return
  }

  // 2. 管理员不能访问普通用户的收藏/评价/订单功能
  if (token) {
    const roles = (userInfo.role || 'user').split(',').map(s => s.trim())
    const adminBlocked = ['/user/favorites', '/user/reviews', '/order/list', '/order/pay']
    if (roles.includes('admin') && adminBlocked.some(p => to.path.startsWith(p))) {
      next('/admin'); return
    }
  }

  // 3. 已登录访问登录/注册页 → 按角色跳转
  if ((to.path === '/login' || to.path === '/register') && token) {
    const roles = (userInfo.role || 'user').split(',').map(s => s.trim())
    if (roles.includes('admin')) next('/admin')
    else if (roles.includes('host')) next('/host')
    else next('/home')
    return
  }

  // 4. 角色权限校验
  if (to.meta.role) {
    const roles = (userInfo.role || 'user').split(',').map(s => s.trim())
    if (!roles.includes(to.meta.role) && !roles.includes('admin')) {
      next('/home'); return
    }
  }

  next()
})
```

```js

  response => {
    const res = response.data
    if (res.code !== 200) {
      ElMessage.error(res.message || '请求失败')      // 业务错误提示
      return Promise.reject(new Error(res.message))
    }
    return res   // 只返回 data，简化后续 .then() 处理
  },
  error => {
    if (error.response) {
      const status = error.response.status
      if (status === 401) {
        // Token 过期或无效 → 清除登录状态并跳转
        localStorage.removeItem('token')
        localStorage.removeItem('userInfo')
        ElMessage.error('登录已过期，请重新登录')

      } else if (status === 403) {
        ElMessage.error('无权限访问')
      } else {
        ElMessage.error(error.response.data?.message || '请求失败')
      }
    }
    return Promise.reject(error)
  }
```
